# edu-rag-assistant

Платформа из двух взаимосвязанных продуктов для УрФУ (ПроКомпетенции):

- **EdAgent** — RAG-ассистент для студентов: методическая поддержка по Agile, Scrum, DevOps через базу знаний
- **RH AI memory** — автономный агент для поиска индустриальных партнёров: анализ отрасли → скоринг компаний → генерация коммуникаций → аутрич → формирование ТЗ проектов

## Репозиторий

```
edu-rag-assistant/
├── backend/    # FastAPI-приложение (Python)
└── frontend/   # (в разработке)
```

Инструкции по запуску — в [backend/README.md](backend/README.md).
